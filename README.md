# RFToolsBuilder - Unofficial ATM11 Fan Build

RFTools building utilities, including the Builder, shape cards and shield systems.

## Unofficial fan version and credits

This is an **unofficial fan-maintained distribution** of a previously compiled compatibility build for Minecraft **26.1.2 / ATM11**. It is not an official McJty release and is not endorsed by McJty or the All the Mods team. Original author: **McJty**, with all original contributors credited by the upstream project. The original MIT license is preserved and included in the JAR.

## Installation

Download `rftoolsbuilder-26.1.2-8.0.0-atm11.jar` from [Releases](https://github.com/victor0hxz/RFToolsBuilder-Unofficial-ATM11/releases). Requirements: Matching McJtyLib and RFTools Base ATM11 builds; NeoForge 26.1.2.109; Java 25. Replace older copies of the same mod; the mod ID is preserved, so do not install this build alongside another copy of the same mod. Use matching versions of McJtyLib and the RFTools modules.

## Validation and limitations

Previously compiled Java 25 artifact found installed in the ATM11 instance and listed in its mod inventory. ZIP integrity, mod metadata and bytecode version verified. Full gameplay functionality was not retested during publication. The exact modified source tree was not located in the inspected folders.

The JAR contains the same production class bytes and resources as the installed artifact; publication only adds the original MIT license notice. Builder and Dimensions retain inherited older dependency declarations in their metadata, which were not corrected or retested in this distribution step. These are prereleases for further compatibility testing, not a guarantee that every machine or dimension workflow has been validated.

## Source availability

This repository currently contains release documentation and audited binaries, **not the exact modified port source**. The matching local source tree was not located. [Upstream source](https://github.com/McJtyMods/RFToolsBuilder/tree/1.21_neo) is provided for attribution and reference and must not be assumed to reproduce this binary. No unmodified upstream code is presented as the source of this port.

Report issues specific to this build to [this repository](https://github.com/victor0hxz/RFToolsBuilder-Unofficial-ATM11/issues), rather than to the upstream authors.
